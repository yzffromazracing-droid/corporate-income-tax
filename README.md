# 法人税区分辞書

国税庁ホームページ（https://www.nta.go.jp/）で公開されている法人税関係の情報を取得し、
キーワード全文検索・出典種別／分野での絞り込みができるようにした静的 Web アプリです。
すべての項目に国税庁の原文ページへのリンクが付きます。

| 出典種別 | 取得元（目次） | 収録単位 | 分野 |
| --- | --- | --- | --- |
| 法人税基本通達 | `/law/tsutatsu/kihon/hojin/01.htm` | 通達番号（例: 9－2－12）ごと | 章（第1章 総則 など） |
| 租税特別措置法関係通達（法人税編） | `/law/tsutatsu/kobetsu/hojin/sochiho/750214/01.htm` | 通達番号（例: 61の4(1)－15の2）ごと | 章（第8章 交際費等の課税の特例 など） |
| 質疑応答事例 | `/law/shitsugi/hojin/01.htm` | 事例ごと | 目次の区分（収益の計上 など） |
| 文書回答事例 | `/law/bunshokaito/hojin/08_1.htm`（項目別） | 事例ごと（本庁・各国税局の回答ページと同じフォルダの別紙ページ） | 目次の区分（寄附金 など） |
| タックスアンサー | `/taxes/shiraberu/taxanswer/code/index.htm#code07`（`/taxanswer/hojin/`） | コード番号ごと | 目次の区分（交際費 など） |

「分野」は各出典の目次に国税庁が付けている区分をそのまま使っています（独自の分類付けはしていません）。

## 構成

- `scripts/fetch_nta.py` … 取得スクリプト（Python 3.9+ 標準ライブラリのみ）。目次ページから各ページを巡回し、本文を抽出して `data/hojin.json` を出力します。
- `data/hojin.json` … 検索用データ
- `index.html` / `app.js` / `style.css` … 検索アプリ（ビルド不要）
- `bunrui.js` … 辞書タブの「益金」「損金」の整理表と説明文

## 使い方

```sh
# データ取得（アクセス間隔は既定 1 秒。取得した HTML は .cache/ に保存され再利用されます）
python3 scripts/fetch_nta.py
python3 scripts/fetch_nta.py --refresh      # キャッシュを捨てて最新を取得
python3 scripts/fetch_nta.py --only sochiho  # 出典を限定（tsutatsu / sochiho / shitsugi / bunsho / taxanswer）

# アプリ起動（fetch で JSON を読むため HTTP サーバー経由で開く）
python3 -m http.server 8000
# → http://localhost:8000/
```

GitHub Pages などの静的ホスティングにそのまま置くこともできます。

### 画面構成（タブ）

デザインは [消費税区分辞書](https://github.com/yzffromazracing-droid/consumption-tax-dictionary) にそろえています。

- **辞書** … 5 出典をまとめてキーワード検索。「益金」「損金」と出典（法人税基本通達／措置法通達／タックスアンサー／質疑応答事例／文書回答事例）・分類で絞り込み
  - **益金／損金** … 益金・損金とそのテーマ（益金 3・損金 16：減価償却、役員給与、交際費等、寄附金、貸倒損失、圧縮記帳 など）ごとに、タイトル・説明文と、関連する通達・タックスアンサー・質疑応答事例・文書回答事例のタイトル（番号）を一覧表示。項目を押すと掲載先の「通達」「国税庁の記事」タブに移動して全文と国税庁の原文リンクを表示（ブラウザの「戻る」で一覧に戻れます）。整理表と説明文は `bunrui.js`（目次の見出し → テーマの対応表）で、説明文は本辞書による概要です。益金・損金の両方にまたがる見出し（有価証券、組織再編成、税額計算など）は含めていません
  - **資本的支出と修繕費** … 損金の右に配置。6 テーマ（意義、形式基準による区分、個別の取扱い、資本的支出後の減価償却、特別償却・圧縮記帳等の特例、事例）ごとに説明文と関連する通達・タックスアンサー・質疑応答事例・文書回答事例の一覧を表示。目次の見出しが一つにまとまっていないため、該当する項目を `bunrui.js` で個別に指定しています（損金の減価償却などと重複して載る項目があります）
  - **繰延資産** … 資本的支出と修繕費の右に配置。6 テーマ（意義と種類、公共的施設等の負担金、権利金・ノウハウの頭金・加入金など、償却期間、償却費の計算・少額の繰延資産、組織再編成・災害損失）ごとに説明文と関連項目 42 件の一覧を表示（`bunrui.js` で個別に指定）
  - **引当金** … 繰延資産の右に配置。4 テーマ（貸倒引当金の通則、個別評価金銭債権、一括評価金銭債権、他の制度の所得計算における引当金）ごとに説明文と関連項目 40 件の一覧を表示（`bunrui.js` で個別に指定。措置法の準備金は含めていません）
  - **役員報酬と給与** … 引当金の右に配置。11 テーマ（概要、役員の範囲・使用人兼務役員、経済的な利益、定期同額給与、事前確定届出給与、業績連動給与・株式報酬、過大な役員給与、退職給与・企業年金、使用人給与・賞与、出向・転籍、賃上げ促進税制）ごとに説明文と関連項目 115 件の一覧を表示（`bunrui.js` で個別に指定）
- **通達** … サブタブ「法人税基本通達」「措置法通達」に分けて、国税庁の目次の順に掲載。章で絞り込み、通達を開くと全文
- **国税庁の記事** … サブタブ「タックスアンサー」「質疑応答事例」「文書回答事例」に分けて掲載。分類で絞り込み、記事を開くと全文

各項目を開くと全文（見出し・段落・表）と国税庁の原文リンクを表示します。図は「［図：…（原文を参照）］」と表示し、丸数字（①）・ローマ数字（Ⅰ）・単位記号（㎡ など）の画像は文字に置き換えています。
タブは URL（`#tab=tsu`、`#tab=tsu&sub=so`、`#tab=nta`、`#tab=nta&sub=qa`、`#tab=nta&sub=bk`）でも直接開けます。`&id=`（例: `#tab=tsu&id=tsutatsu:9-2-12`）を付けるとその項目を開いた状態で表示します。

### 検索のしかた

- スペース区切りで AND 検索（例: `交際費 飲食`）
- 先頭に `-` を付けた語を除外（例: `寄附金 -国外`）
- 全角／半角・大文字／小文字は区別しません。通達番号は `9-2-12` でも `９－２－１２` でも検索できます

## データの扱い

- 本文は国税庁ページの HTML から抽出したテキストのみで、要約・補完・推測による生成は行っていません。
- 掲載内容は取得時点のものです（各項目に質疑応答事例・タックスアンサーの「〜現在」表示を併記）。実務での利用時は必ず原文を確認してください。
- 本アプリは国税庁の公式サービスではありません。
